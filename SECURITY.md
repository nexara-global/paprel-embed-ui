# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Report it privately through [GitHub Security Advisories](https://github.com/nexara-global/paprel-embed-ui/security/advisories/new).

Include the affected package and version, reproduction steps, impact, and any suggested mitigation. We will acknowledge valid reports as quickly as practical and coordinate disclosure after a fix is available.

## Supported versions

Before the first stable release, security fixes are provided on the latest published version only. This policy will be revised when long-term support versions are introduced.

Never include App Connect client secrets, access tokens, customer data, or production credentials in a report.
